## What is machine-checked

1. ArithmeticKernel.lean: 20 arithmetic lemmas (subtract-B, subtract-C and interior-shift arithmetic), compiled without Mathlib.
2. GenKernel.lean: an inductive closure `Gen` of zero under the ten generators A, E0-E3, B0-B3, C, and the theorem
   `Gen a0 a1 a2 a3 k <-> Feasible a0 a1 a2 a3 k`, where Feasible means all four coordinates are >= 0 and k <= a_i + a_j for every pair i < j.
   `Gen -> Feasible` is by induction on Gen. `Feasible -> Gen` is by induction on a bound k <= n, using the zero-coordinate reductions, the k = 1 reduction and the all-positive C reduction.
   Locally observed axioms for the four GenKernel theorems: propext, Quot.sound. No sorryAx.

## Addendum: facet and lattice lemmas (core Lean, Facets.lean)

- facets_irredundant: for each of the ten forms (a_i >= 0 and a_i + a_j - k >= 0) an explicit integer point has that form equal to 0 and the other nine strictly positive.
- interior_witness: the point (1,1,1,1,1) makes all ten forms strictly positive (full-dimensionality witness).
- lattice_spanned: every integer point is an integer combination of A, E0-E3, so the group generated by the semigroup is Z^5.
